# PenguinVault — GRUB2 theme for Ventoy
#
# Deliberately self-contained: the only external asset is background.png,
# which ships alongside this file. No pixmap styles are referenced, so a
# missing image can never leave the menu unrenderable — GRUB falls back to
# the flat colours below.
#
# Icons are looked up as icons/<menu class>.png relative to this file.
# Ventoy derives that class from the ISO filename, or from a menu_class
# rule in ventoy.json.
